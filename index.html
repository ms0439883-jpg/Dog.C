🐾 設定帳號系統
毛緣配對需要 Supabase 來儲存您的收藏。只需 2 分鐘，完全免費！
  1. 前往 supabase.com，免費建立帳號並新增專案
  2. 在專案的 Settings → API 找到 Project URL 和 anon public 金鑰
  3. 在 SQL Editor 執行以下建表指令：
CREATE TABLE liked_pets (
  id uuid DEFAULT gen_random_uuid() PRIMARY KEY,
  user_id uuid REFERENCES auth.users NOT NULL,
  animal_id text NOT NULL,
  pet_data jsonb,
  created_at timestamptz DEFAULT now(),
  UNIQUE(user_id, animal_id)
);
ALTER TABLE liked_pets ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Users manage own likes" ON liked_pets
  USING (auth.uid() = user_id)
  WITH CHECK (auth.uid() = user_id);
